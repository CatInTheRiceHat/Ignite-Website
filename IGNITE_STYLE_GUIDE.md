# Ignite Program Style Guide

Last Updated: June 7, 2026  
Primary Contact: Elaine Che

This document outlines the visual identity and branding standards for the Ignite Summer Program. All program materials, including slide decks, websites, classroom headers, and marketing collateral, should follow these guidelines to keep Ignite consistent, energetic, playful, and easy for students to understand.

## 1. Core Visual Identity

Ignite should feel modern, warm, student-friendly, and playful. The brand should avoid a cold corporate style. Use rounded shapes, friendly icons, bright orange accents, mascot artwork, and simple layouts that feel welcoming to middle and high school students.

### Color Palette

The current website palette is the source of truth for Ignite digital materials.

| Element | Hex Code | Usage |
| --- | --- | --- |
| Primary Background | `#FFF8F0` | Default page background and soft section backgrounds. |
| Primary Orange | `#F07B2A` | Main brand color, CTAs, hero sections, active nav states, icons, mentor accents, and key headings. |
| Dark Orange | `#D46A20` | Hover states, button depth, darker orange accents, and stronger emphasis when primary orange needs contrast. |
| Text Charcoal | `#1A1A2E` | Main headings, high-contrast text, dark announcement bar, and important labels. |
| Text Light | `#4A4A5E` | Body copy, descriptions, secondary text, and card details. |
| Card White | `#FFFFFF` | Cards, nav surfaces, form panels, and content blocks. |
| Success Green | `#58CC02` | Success states only, such as completed application messages. |

### Typography

Ignite uses a three-font hierarchy from Google Fonts:

| Use | Font | Notes |
| --- | --- | --- |
| Display Titles | Rammetto One | Big page titles, hero headings, section moments, and playful display text. |
| Headings | Poppins | Subheaders, card titles, nav labels, buttons, and bold UI labels. |
| Body Text | Nunito | Paragraphs, descriptions, form text, supporting copy, and general readable content. |

### Imagery And Icons

- Use the Ignite mascot/fire character as the primary visual personality.
- Use course header artwork for course cards, Google Classroom headers, and related class materials.
- Use rounded profile photos for mentors and staff.
- Use Lucide-style outline icons in UI controls and detail rows.
- Decorative images should use empty alt text. Informational images should have useful alt text.

## 2. Design Standards & Accessibility

- Layouts should be clean and spacious, with rounded cards, large headings, and clear visual hierarchy.
- Cards should generally use large rounded corners, soft shadows, and orange accent borders or strips.
- Buttons should be rounded, high-contrast, and action-oriented.
- Avoid cluttered slides or pages. Use one main idea per section whenever possible.
- Keep text readable on Zoom and mobile. Favor large font sizes and generous line spacing.
- Maintain strong contrast, especially on orange or image backgrounds.
- Use `#1A1A2E` or white for high-contrast text depending on background.
- Do not place long text directly over busy images unless there is a strong overlay.
- Add alt text for meaningful images in digital documents and websites.

## 3. Tone And Voice

The Ignite voice should sound:

- Energetic: exciting, optimistic, and forward-looking.
- Hands-on: focused on practical activities students can try.
- Discussion-heavy: built for interaction, questions, chat, Slido, and reflection.
- Supportive: encouraging curiosity, confidence, and “finding your fire.”
- Student-friendly: clear, direct, warm, and never overly formal.

Use short sentences and friendly phrasing. Avoid corporate wording, dense academic language, and overly polished marketing jargon.

## 4. Component Style Notes

- Navbar: white translucent surface with orange active links and a charcoal announcement bar.
- Hero sections: orange or image-led, with white display text.
- Course cards: white cards with classroom-style image headers, course icons, mentor avatars, and compact descriptions.
- Mentor cards: white cards with orange accents; co-founder cards can use orange treatment to stand apart.
- Forms: white rounded panels on cream backgrounds, with orange focus states and large inputs.
- Footer: orange background with white text and mascot artwork.

## 5. Gamma Prompting Standards

When using AI tools like Gamma to generate presentation decks, include this style block:

```text
Style Reference:

Brand: Ignite Summer Program
Background: #FFF8F0
Primary Accent: #F07B2A
Secondary Accent: #D46A20
Text: #1A1A2E for headings, #4A4A5E for body text
Fonts: Rammetto One for display titles, Poppins for headings, Nunito for body text
Layout: Modern, rounded shapes, minimalist, playful, student-friendly
Imagery: Use warm mascot/classroom visuals, course artwork, and friendly icons
Accessibility: Large fonts, high-contrast text, generous spacing
Tone: Energetic, hands-on, discussion-heavy, supportive
Avoid: Corporate design, cluttered slides, tiny text, generic stock imagery
```
